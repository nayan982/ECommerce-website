# ⚡ Electronic E-Commerce Website

A full-stack electronic e-commerce web application where users can browse electronic products, add items to cart, and place orders online.

The project includes a frontend client for users and a backend server for handling APIs, authentication, products, and orders.

---

# 🚀 Features

## 👤 User Features

* Browse electronic products
* View product details
* Add/remove products from cart
* User authentication
* Place orders
* Responsive design

---

## ⚙ Backend Features

* REST API with Express.js
* MongoDB database integration
* Product management
* Order management

---

# 🧰 Tech Stack

* React
* Tailwind CSS
* Node.js
* Express.js
* MongoDB

# ⚙️ Installation

## 1️⃣ Clone Repository

```bash
git clone https://github.com/username/electronic-ecommerce-website.git

cd electronic-ecommerce-website
```

---

# 📦 Install Dependencies

## Client

```bash
cd client
npm install
```

## Server

```bash
cd server
npm install
```

---

# 🔑 Environment Variables

Create a `.env` file inside the `client` folder.

```env

VITE_BACKEND_URL=your_backend_url

```
Create a `.env` file inside the `server` folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

```

---

# ▶️ Run The Project

## Start Client

```bash
cd client
npm run dev
```

## Start Server

```bash
cd server
npm start
```
